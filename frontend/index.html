O que é o DIEESE 360

Uma plataforma permanente de coleta, tratamento e visualização de dados econômicos e socioeconômicos — construída para dois usos complementares: dar aos técnicos do DIEESE a base de dados pronta para elaborar os boletins de conjuntura, e oferecer a todo o DIEESE um painel de acompanhamento em tempo real dos principais indicadores do país.

Os dados vêm de fontes oficiais — IBGE, Banco Central, Tesouro Nacional, MDIC, FMI, BNDES e publicações do próprio DIEESE — coletados automaticamente por 35 motores de ingestão, com rastreabilidade completa de fonte e metodologia em cada indicador (clique num cartão para ver os detalhes e o gráfico).

Organizado por dimensão

Cada dimensão reúne os indicadores de um mesmo domínio da conjuntura. A navegação completa, com todos os indicadores de cada dimensão, fica disponível depois do login.

Uma amostra dos indicadores

Dez indicadores de macroeconomia, atualizados automaticamente. Clique em qualquer cartão para ver a explicação, a fonte e o gráfico da série histórica completa.
