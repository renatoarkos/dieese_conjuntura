# DIEESE Conjuntura | Plataforma de Inteligência Socioeconômica

## Objetivo geral

Desenvolver uma plataforma permanente de coleta, tratamento, armazenamento, análise, visualização e interpretação de dados econômicos e socioeconômicos destinados à análise de conjuntura realizada pelo DIEESE.

## Fase atual

Discovery → Pesquisa → Requisitos → Arquitetura.

## Estrutura de diretórios

- `docs/00-visao-geral/` — visão geral do projeto.
- `docs/01-requisitos/` — requisitos funcionais e não funcionais.
- `docs/02-arquitetura/` — arquitetura da plataforma.
- `docs/03-metodologia/` — metodologia de pesquisa, tratamento e análise.
- `docs/04-fontes/` — documentação das fontes de dados.
- `docs/05-indicadores/` — catálogo mestre de indicadores.
- `docs/06-teorias-e-relacoes/` — biblioteca de relações econômicas.
- `docs/07-divulgacoes/` — calendários de divulgação oficiais.
- `docs/08-decisoes-adr/` — registros de decisões arquiteturais (ADR).
- `docs/09-backlog/` — backlog do projeto.
- `research/literatura/` — literatura de referência.
- `research/fontes/` — pesquisa sobre fontes de dados.
- `research/benchmarks/` — benchmarks e referências comparativas.
- `research/notas/` — notas de pesquisa.
- `data/reference/` — dados de referência.
- `materiais/originais/` — documentos de referência fornecidos pelo DIEESE; devem ser preservados e não modificados.

## Orientação para agentes

Qualquer agente que for trabalhar neste repositório deve ler o arquivo `CLAUDE.md` antes de executar qualquer tarefa.

## Aviso sobre materiais originais

O diretório `materiais/originais/` contém documentos de referência que devem ser preservados. Nenhum arquivo ali deve ser movido, renomeado, editado ou excluído.
